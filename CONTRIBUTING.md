# Contributing

Small, focused improvements are welcome.

1. Fork the repository and create a branch.
2. Keep the wrapper independent of the At0mFlow product and its private code.
3. Run `./tests/Run-Tests.ps1`.
4. Analyse `./src` with errors and warnings enabled.
5. Open a pull request explaining the behaviour change.

Please do not submit product code, credentials, customer scripts, AI prompts,
scoring systems, migration logic or other confidential material. Test fixtures
must be synthetic.
