# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Send
the details through the contact channel at [at0mflow.com](https://at0mflow.com/)
and include `At0mFlow-PSAnalyzer security` in the subject or message.

## Data handling

This tool runs locally and passes local file paths to the installed
PSScriptAnalyzer module. It contains no telemetry, upload, authentication or
network code. Installing dependencies and cloning the repository are separate
operations handled by PowerShellGet and Git.
